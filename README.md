# BDC3200 — симулятор панелегиба

Автономный браузерный тренажёр для визуализации последовательности гибов листового металла и геометрической проверки модели.

## Файлы
- **index.html** — приложение-симулятор: откройте в современном браузере; сборка не требуется.
- **Panel-Bender-Knowledge-Base.md** — база знаний, сведения о технологии и источниках.

## Запуск
Скачайте `index.html` и откройте локально в браузере.

Для публикации через GitHub Pages откройте Settings → Pages и выберите источник Deploy from a branch → main → /(root). Сайт станет доступен после завершения публикации. До проверки Pages не считайте адрес работающим.

## Ограничения
Программа — исследовательская геометрическая модель, а не заводское ЧПУ. Реальные ходы осей, траектории и технологичность необходимо сверять с документацией и оборудованием. Симуляция острых внутренних углов (более 90° отклонения полки) помечается неподтверждённой. Ранее обсуждавшиеся баги следует проверять при дальнейших доработках.

**Все следующие изменения проекта BDC3200 вносить в репозиторий `ArmeecNT/BDC` (ветка `main`).**
