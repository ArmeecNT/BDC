# Панелегибы: технология, инструмент и база знаний для BDC3200

Дата проверки источников: **8 октября 2026 года**. Рабочая версия: **1.0**.

Материал собран для дальнейшего развития BDC3200-Simulator.html. Изучены открытые технические материалы SENFENG, Salvagnini, Prima Power, TRUMPF и RAS, две научные публикации, документация по развёрткам и материалам. Четыре официальных ролика Salvagnini визуально разобраны по выборке кадров. Это систематизированная база доступных источников, а не утверждение о просмотре всего интернета или доступе к закрытым заводским данным.

Обозначения: **подтверждено** — прямо указано в источнике; **инженерный вывод** — вывод из геометрии или сопоставления; **параметр проекта** — принятое пользователем правило текущей модели, не универсальная характеристика панелегибов.

## 1. Что происходит при гибке

Лист удерживается прижимом и нижней опорой. Выступающую часть формирует гибочный нож, а основная удерживаемая область листа остаётся неподвижной во время отдельного гиба. Между гибами подающее устройство перемещает лист к следующей линии; для следующей стороны меняется ориентация детали. Prima Power прямо описывает последовательность одной стороны от внешнего гиба к внутреннему. [2]

| Узел | Назначение | Что учитывать в модели |
|---|---|---|
| Верхний прижим | Удерживает лист и задаёт доступный рабочий проём | Контур, сборку секций, контактную область, раскрытие |
| Нижняя опора / контрнож | Поддерживает удерживаемую часть возле линии гиба | Носик, уступы, зазор по толщине, свободное пространство ниже листа |
| Нижний гибочный нож | Формирование вверх в принятой системе координат | Рабочую кромку и её путь |
| Верхний гибочный нож | Формирование вниз в принятой системе координат | Доступ снизу/сверху, обход сформированных участков |
| Манипулятор / подача | Базирование, линейные подачи, повороты | Фактическую область захвата, отверстия, опору и потерю базы |

Salvagnini перечисляет четыре универсальных инструмента: верхний и нижний ножи, контрнож и прижим. Для P4 движение ножей управляется интерполяцией. [1] Названия осей, знаки и конструктивное объединение ножей необходимо брать из документации конкретного станка; они не определяются этим общим перечнем.

Нужно различать архитектуры. TRUMPF описывает C-образную раму с двумя инструментами и небольшим эллиптическим движением. [6] RAS в материалах по folding описывает поворот гибочной балки вокруг опорной точки. [10] Поэтому перенос кинематики одного производителя на другой без проверки неверен.

## 2. Последовательность: сторона и цепочка гибов

**На одной стороне:** внешний гиб → следующие гибы по направлению к дну. Такое выполнение прямо подтверждено руководством Prima Power. [2] Ранее сформированные внешние полки перемещаются вместе с участком, который гнётся следующим. Это требует проверки всей цепочки, а не только текущей полки.

**Между сторонами:** порядок должен обеспечивать доступ прижима, ножей и захвата. Для нашей конфигурации сохраняется заданный пользователем порядок «две короткие → две длинные». Это правило проекта. Оно не является обязательным для всех панелегибов: RAS допускает обработку длинной стороны до короткой при смене инструмента внутри цикла. [9]

**Инженерный вывод:** выбирать порядок только по длине сторон недостаточно. Если после очередного гиба закрывается доступ к следующей линии или готовая деталь запирается на прижиме, такой маршрут не подходит. Смена порядка может помочь, но при фиксированном инструменте допустимого маршрута иногда нет. Полный путь должен включать раскрытие, поворот, следующую подачу и извлечение. [17]

Пример для четырёх сторон с тремя гибами на каждой: `В3 → В2 → В1 → Г3 → Г2 → Г1 → А3 → А2 → А1 → Б3 → Б2 → Б1`. Номер 1 — ближайший к дну. Это иллюстрация принятого маршрута проекта, а не универсальная программа контроллера.

## 3. Операции и их доступность

| Операция | Принцип | Что нужно подтвердить для конкретной комплектации |
|---|---|---|
| Положительный / отрицательный гиб | Полка формируется по разные стороны исходной плоскости | Ходы, доступ инструмента и опору детали |
| Несколько гибов на стороне | Последовательная подача внешних линий к внутренним | Минимальные полки, промежуточные формы, область захвата |
| Z-профиль | Смещение с противоположными поворотами | Расстояние между линиями и свободное место у прижима |
| C-профиль / возврат внутрь | Полка возвращается в область уже сформированной детали | Боковой проём, форму прижима и извлечение |
| Подгиб с обжимом | Предварительное формирование и отдельное закрытие кромки | Инструмент и режим закрытия, усилие, конечный зазор |
| Большой радиус | Последовательность небольших углов и подач | Число шагов, шаг подачи и допустимую гранёность |
| Частичный гиб / локальный язычок | Обрабатывается только часть линии | Вспомогательные ножи или секционную оснастку |

Prima Power FBe предусматривает несколько гибов на сторону, смену направления, радиусные и уплощённые операции; загрузка, поворот и выгрузка на этой модели ручные. [3] TRUMPF подтверждает получение разных радиусов одним комплектом за счёт увеличения количества шагов. Каталог также показывает отдельные ограничения Z-гибов и специальные инструменты. [4]

Salvagnini CLA предназначен для локальных положительных и отрицательных гибов, более коротких, чем сторона листа. Для скрытых, узких и некоторых радиусных форм предусмотрен P-инструмент. [11] Наличие универсальных ножей не означает доступность любой локальной формы стандартной комплектацией.

**Инженерный вывод для симуляции:** обычный поворот полки нельзя автоматически считать обжимом кромки. У обжима есть стадия контакта слоёв и закрытия зазора. В нашей системе внутренний угол 180° означает плоское состояние; отраслевой «подгиб на 180°» описывает другую систему углов и другую операцию.

## 4. Инструмент: три разных вида переналадки

| Возможность | Смысл | Состояние нашего проекта |
|---|---|---|
| Универсальный профиль | Одни рабочие ножи используются для разных углов | Принято |
| Автоматическое изменение длины прижима | Секции адаптируются к размеру или стадии обработки | Не моделируется; длина фиксирована |
| Автоматическая смена профиля / вспомогательной оснастки | В рабочую область вводятся другие инструменты | Исключена из текущей комплектации |

У Salvagnini P2 автоматический прижим меняет длину в том числе внутри цикла, при этом производитель пишет об отсутствии ручной переоснастки. [11] Следовательно, фразы «без переоснастки» и «фиксированная длина прижима на весь цикл» не равнозначны.

В каталоге TRUMPF представлены стандартные прижимы, дополнительные ENW, вспомогательные ZBW, угловые horn-инструменты и разные захваты. Некоторые формы невозможны стандартным прижимом. [4] RAS показывает поворотные угловые roto-foot-инструменты для боковых возвратов. [9] Эти возможности не относятся автоматически к выбранному обычному прижиму BDC3200.

**Инженерный вывод:** выбранную фиксированную сборку надо проверять во всех операциях. Длина должна одновременно обеспечивать достаточную область прижима и проходить между уже сформированными короткими бортами. Формула «длинная часть минус два зазора» — начальная геометрическая оценка; одной её недостаточно для цепочек с возвратами.

## 5. Радиус детали, радиус ножа и путь движения

Для идеализированного сечения постоянной толщины:

`Rнаруж = Rвнутр + t`.

Это геометрическая связь. Минимальный технологический радиус дополнительно зависит от материала, состояния поставки, ориентации прокатки и способа формования. SSAB отдельно различает радиус инструмента и достижимый внутренний радиус материала. Их рекомендации относятся к конкретным маркам и операциям на прессе; переносить численные пределы на тонколистовой BDC нельзя. [13]

В каталоге Prima Power для ряда панелегибов указан минимальный наружный радиус **1,5–2 толщины**. [2] Поэтому принятое в нашей модели `Rнаруж = t`, откуда `Rвнутр = 0`, является упрощением проекта, а не общим технологическим законом.

Также необходимо разделять:

- скругление рабочей кромки ножа;
- сформированный радиус листа;
- траекторию выбранной точки ножа;
- траекторию его центра скругления;
- движение всей рамы и подвод к контакту.

При идеальном наружном касании двух круговых поверхностей расстояние между центрами равно сумме радиусов. **Наш инженерный вывод:** формула `Rдвиж = Rнаруж + Rножа` описывает частную модель касания, но сама по себе не определяет заводскую программу осей. TRUMPF указывает эллиптическое движение, Salvagnini — интерполяцию. [6, 1]

В научной работе Kunze и соавторов рассматриваются разные стратегии контакта: сохранение контакта с граничной точкой и движение с перекатыванием. Реальный путь учитывает контакт, трение, материал и деформации системы; модели сверяются с измерениями. [15]

## 6. Развёртка и автоматический K-фактор

SOLIDWORKS определяет K как отношение расстояния нейтрального слоя от внутренней поверхности к толщине и поддерживает таблицы K, в том числе по материалу. Припуск:

`BA = β × (Rвнутр + K × t)`, где β — угол поворота **в радианах**. [12]

Если α — внутренний угол между соседними прямыми участками в принятой системе проекта, то `β = (180° − α) × π / 180`.

**Наш инженерный вывод:** автоматический расчёт по середине толщины даёт `K = 0,5`, но не определяет положение нейтрального слоя при реальной пластической гибке. Для производственной точности нужна таблица или калиброванная модель для материала, толщины, радиуса и режима.

Практический способ наполнить такую таблицу:

1. Измерить толщину и исходную длину полосы.
2. Выполнить гиб на выбранном станке и оснастке.
3. Измерить конечный угол, внутренний радиус и прямые участки между касательными.
4. Найти экспериментальный припуск `BA = длина полосы − сумма прямых участков`.
5. Рассчитать `K = (BA / β − Rвнутр) / t`.
6. Повторить для нужных материалов и режимов, проверить повторяемость.

Эта формула — алгебраическое преобразование определения BA; процедура предложена для калибровки нашей базы. Если размеры сняты по наружным вершинам, сначала надо преобразовать их к прямым участкам между касательными. Подстановка наружных размеров непосредственно вместо таких участков даёт другую длину.

Пример текущей модели: при `t = 1 мм`, `Rвнутр = 0`, `K = 0,5` и повороте 90° припуск равен **0,7854 мм**. Это точный результат формулы для принятых параметров, не измеренный припуск BDC3200.

## 7. Материал, пружинение и прямолинейность

После снятия нагрузки лист частично возвращается к исходной форме — возникает пружинение. SSAB подтверждает необходимость перегиба и связь эффекта с прочностью материала. Их таблицы для толстых сталей на прессе здесь используются только для физического объяснения, не как настройки BDC. [14]

Для панелегибов есть разные способы компенсации. TRUMPF описывает бесконтактный ACB Laser с коррекцией угла. [5] Prima Power использует базу коррекции углов. [3] Исследование LEAN PANEL BENDER описывает определение класса материала по измеренным усилиям и корректировку пути на основе результатов моделирования. [16]

Работа COMPLAS также рассматривает компенсацию прогиба инструмента в двух направлениях и проверку столкновений с учётом деформаций. [15] **Инженерный вывод для нашей модели:** четыре ровных угла на жёсткой геометрии не доказывают прямолинейность длинного реального борта или точность размера после разгрузки.

В технологической записи полезно хранить: марку и состояние материала, фактическую толщину, направление прокатки, покрытие/плёнку, радиус, угол под нагрузкой и после раскрытия, длину линии, поправку и результаты контрольных измерений. Это предлагаемый состав данных, а не список параметров конкретного контроллера.

## 8. Проверка полного цикла

ADH подчёркивает необходимость проверять плоскую заготовку, каждую промежуточную форму, финальный гиб и извлечение. Прохождение габаритов в каталоге не означает, что деталь сохраняет доступный захват и опору. [17]

**Предлагаемая последовательность проверки для нашей симуляции:**

1. Идентифицировать комплектацию станка и фиксированную сборку инструмента.
2. Проверить материал, толщину, длину каждой линии, угол и радиус.
3. Проверить развёртку, угловые вырезы, ближайшие отверстия и область захвата.
4. Для очередного гиба проверить входную форму детали и базирование.
5. Проверить раскрытие прижима и подвод к выбранной линии.
6. Проверить прижатие: опору, контактную длину и отсутствие непредусмотренного контакта полок.
7. Проверить движение ножей и объём, который занимают все движущиеся участки листа.
8. Проверить отвод ножей и раскрытие прижима.
9. Проверить следующую подачу либо отвод и поворот детали.
10. Повторить для всех гибов и проверить выход готовой детали из инструмента.
11. Сопоставить геометрию с пробной деталью и результатами измерений.

| Возможный контакт | Что важно |
|---|---|
| Полка ↔ полка / дно | Толщина, радиусные зоны, взаимное положение цепочек |
| Полка ↔ прижим | Корпус и торцы, весь ход раскрытия, возвраты |
| Полка ↔ стол / контрнож | Отрицательные гибы, уступы, место под листом |
| Полка ↔ нож / рама | Подвод, формование, отвод обоих ножей |
| Деталь ↔ захват | Доступный материал, возможность следующего базирования |
| Деталь ↔ рабочее пространство | Полный объём при повороте и извлечении |

Проверка с шагом 1° полезна для первичного поиска пересечений, но это выборка, которая может пропустить узкий интервал контакта. **Инженерный вывод:** для строгой проверки нужны адаптивные шаги по зазору или проверка непрерывного перемещения. Для CAD-программ TRUMPF заявляет проверку столкновений при изменении программы. [18] Наша геометрическая самопроверка пока охватывает лишь часть перечисленных контактов.

## 10. BDC3200: подтверждённые данные и расхождения

На действующей странице SENFENG приведены следующие показатели BDC3200. [7]

| Параметр | Текущая публичная таблица SENFENG | Применение к нашему проекту |
|---|---|---|
| Максимальная длина гибки | 3200 мм | Соответствует выбранной модели |
| Габарит L×W | 3200×1500 мм | В предоставленном пользователем варианте используется ширина 1250 мм; требуется паспорт именно этой комплектации |
| Высота | 200 мм; 300 мм опция | Значение зависит от поставленной опции |
| Минимальная толщина | 0,35 мм | Отдельно подтвердить по материалу и операции |
| Холоднокатаная сталь | До 2,0 мм | Максимум не заменяет проверку длины, угла и материала |
| Нержавеющая 304 | До 1,5 мм | Не применять как предел всех нержавеющих марок |
| Алюминий | До 2,5 мм | Уточнить сплав и состояние поставки |
| Число осей | 16 для BDC3200 в таблице | Общий текст страницы упоминает 13 осей; таблица и фактическая комплектация важнее общего описания |
| Заявленная скорость | До 0,2 с/гиб | Не равна времени готовой детали с подачей, поворотами и загрузкой |

На этой же странице автоматическая смена и вспомогательные инструменты указаны как опции. [7] Для нашего проекта сохраняется выбранная комплектация без автоматической смены.

## 11. Сопоставление с сохранённой симуляцией 4.0

Исходник текущего проекта проверен локально. В этом исследовании код симуляции не менялся.

| Реализованное правило | Статус после исследования | Направление последующей работы |
|---|---|---|
| Основная область детали удерживается во время гиба | Соответствует общему принципу | Добавить контактную область и контроль опоры |
| Внешние гибы до внутренних на одной стороне | Подтверждено Prima Power | Сохранить как базовый маршрут |
| Короткие стороны до длинных | Параметр нашей комплектации | Сохранять; альтернативы вводить только с проверкой оборудования |
| Одна длина обычного прижима на весь цикл | Параметр проекта | Проверять полный фиксированный инструмент во всех стадиях |
| Верхний и нижний ножи на общей жёсткой раме | Принятая схема по предоставленным материалам | Уточнить заводскую кинематику BDC |
| R2 рабочей кромки | Задано пользователем | Подтвердить размер на реальном инструменте |
| Rнаруж = t, Rвнутр = 0 | Геометрическое упрощение | Позднее добавить технологические радиусы по материалу и комплекту |
| K = 0,5 по средней линии | Геометрический расчёт | Добавить автоматический выбор из калиброванных таблиц |
| Круговой путь центра R = t+2 | Частная модель касания | Позднее заменить/дополнить подтверждённым законом движения |
| Проверка прямых полок через 1° | Частичная проверка | Добавить радиусы, дно, прижим, раму, захват и извлечение |
| Произвольные полки в цепочках | Геометрические возможности | Ввести ограничения минимальных полок и доступности оснастки |
| Схематичные угловые вырезы | Недостаточно для выпуска развёртки | Построить точные контуры вырезов по соседним цепочкам |

## 12. Что нужно для перехода к производственной проверке

Это перечень недостающих исходных данных, а не обязательный запрос пользователю прямо сейчас:

- паспорт и перечень опций конкретного BDC3200;
- размерные профили прижима, нижней опоры и обоих ножей, включая радиусы;
- фактическая сборка секций, торцевые элементы и рабочие длины;
- пределы осей и заводское описание подведения, формования, отвода;
- геометрия и допустимые области захвата/перехвата;
- минимальные полки и расстояния между линиями для стандартной оснастки;
- допустимые отрицательные гибы, возвраты, острые углы и режимы обжима;
- образцы реальных заготовок и измерения после гибки.

Приоритет для будущего развития: **объёмные столкновения и извлечение → реальные минимальные полки/проёмы → калибровка развёртки и радиуса → заводская траектория → пружинение и деформации**. Это инженерное предложение для нашего проекта, не утверждение о готовности функций.
